## Summary

This study introduces the **Adaptive Particle Batch Smoother (AdaPBS)**, an iterative data-assimilation method that combines particle smoothing with adaptive multiple importance sampling. The method is designed to improve resilience to ensemble collapse and to adjust computational effort according to problem complexity.

AdaPBS is evaluated using snow-depth assimilation experiments ranging from a simplified temperature-index model to distributed simulations with the Flexible Snow Model.
